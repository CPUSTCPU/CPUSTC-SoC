# CPUSTC-Soc

[中文](README.md) | [English](README.en.md)

CPUSTC-Soc is a Chisel/Verilog/Vivado SoC for the `xc7a200t` FPGA board. It integrates CPUSTCore, DDR3, AXI/APB buses, storage, networking, display, USB, camera capture, and optional accelerators. The active Vivado project is:

```text
fpga/xc7a200t/CPUSTC-SoC/CPUSTC-SoC.xpr
```

## Overview

Chisel owns the SoC integration and bus glue. Existing Verilog/Vivado IPs implement board interfaces and peripherals, while CPUSTCore is connected through `IP/myCPU/core_top.sv`. Generated SystemVerilog and standalone SpinalHDL IPs are consumed by Vivado.

The CPU core remains a separate CPUSTCore project. Copy the `CPU.sv` generated by CPUSTCore into `IP/myCPU/`, then run `python3 scripts/gen_cpustcore_adapter.py` to generate `core_top.sv` in the same directory. The Vivado project reads both files from `IP/myCPU/`.

```text
CPUSTCore
   |
   v
CPU AXI -> local AXI slave mux -> MMIO / CPU DDR path
                                      |
DMA masters (MAC, NAND, VGA, LCD, USB, SDIO, camera, TensorCore, 2D GPU)
                                      v
                              DDR AXI interconnect -> MIG -> DDR3
```

See [`docs/architecture.md`](docs/architecture.md) for the complete address map, clock/reset scheme, and peripheral wiring. Detailed engineering documents are maintained in Chinese under `docs/`.

## Status

- The active target is `xc7a200t`; the Vivado top module is `soc_top`.
- The root Chisel project and the three SpinalHDL subprojects build with SBT.
- Generated RTL is written to the ignored `generated/xc7a200t/` directory.
- A Vivado 2023.2 implementation baseline exists, and the current source has been validated on the target board.
- Optional peripherals are controlled by `SocFeatureConfig`; top-level ports and the Vivado AXI interconnect remain fixed.

## Requirements

- Linux, Git, and Python 3.
- A JDK and the SBT version in `project/build.properties` (currently 1.12.10).
- Vivado 2023.2 for bitstream generation, targeting `xc7a200tfbg676-2`.
- Fixed LiteSDCard, LiteX, Migen, and verilog-axi checkouts when regenerating LiteSDCard. Revisions and commands are documented in [`IP/LiteSDCard/UPSTREAM.md`](IP/LiteSDCard/UPSTREAM.md).

## Quick Start

Run from the repository root:

```bash
# Compile the Chisel SoC
sbt compile

# Generate generated/xc7a200t/CPUSTCSoc.sv
sbt run

# Generate the SoC and all three SpinalHDL IPs
./sbt_run_all.sh

# Run root-project tests
sbt test
```

After changing CPUSTCore RTL, regenerate and check the adapter:

```bash
python3 scripts/gen_cpustcore_adapter.py
python3 scripts/gen_cpustcore_adapter.py --check
```

After changing a local Vivado IP or Block Design, save the project-local
`.srcs` source configurations and stage them directly with Git:

```bash
git add fpga/xc7a200t/CPUSTC-SoC/CPUSTC-SoC.xpr \
  fpga/xc7a200t/CPUSTC-SoC/CPUSTC-SoC.srcs
```

The project-local `.srcs` files are the single source of truth; they are not
copied into `IP/xilinx_ip`.

The complete build and Vivado flow is described in [`docs/build.md`](docs/build.md).

